# Project 1 – Expectations

## Model 1: Word Embeddings + Classifier

**Expected best test accuracy: 60%**

I expect the model to perform above the random baseline of 50%, as pretrained word embeddings contain useful semantic information.

## Model 2: Word Embeddings + RNN + Classifier

**Expected best test accuracy: 70%**

I expect the RNN model to outperform the first model because it can learn more sophisticated representations of the input sequences, including word order and contextual relationships. This should help it identify the more plausible hypothesis.

## Comparison

I expect the RNN model to outperform the embedding-only model by approximately 10 percentage points.
